# Dashboard templates

Whole pages, built from the components, to copy and fill in rather than rebuild. A template is not a
component and nothing in it is new: it proves the components compose and gives a builder a verified starting
point. Web templates live in `skills/gushwork-web/templates/`; dashboard templates live in
`skills/gushwork-dashboard/templates/`.

## Analytics overview template

**Purpose.** A Monitor-and-explore screen: how a thing performed over a period, against the previous period,
broken down and listed. Use it as the start for an overview, a campaign report or a weekly readout. Do not use it
for a settings page, a detail page or an explorer with a query panel; those follow the other recipes in
`patterns.md`.

**Files.** `skills/gushwork-dashboard/templates/analytics-overview/analytics-overview.html`, one static file
linking `foundation/tokens.css`, `exports/dashboard/dashboard.css` and `dashboard.js`. A copy is served to the
review drawer at `/previews/dashboard/pages/analytics-overview.html`, with its links made absolute and the stamp's
registry URL blanked so the build notice stays quiet while it is being reviewed; it is regenerated by
`scripts/build-dashboard-css.sh`, never edited.

**How to use.** Copy the folder to the new project and edit the copy. Do not reference another built dashboard.
Replace the sample copy and figures, keep the `Sample data` Badge until real data replaces them, change the
stamp's `components` list to exactly what the page uses, and delete what the screen does not need. Every figure in
it is invented.

**What it contains, in order.** `app-shell` with a grouped `sidebar`, `account-row` and `theme-menu` →
`page-header` (title, `Sample data` Badge, a comfortable and compact density switch, Export) → `tabs-underline` →
`time-range-bar` (range, granularity, comparison) → four `stat-card`s with `delta-pill`s and sparklines →
`chart-frame` with a `line-chart` (this period against the previous one) → `horizontal-bar-chart` by channel →
`funnel` → `data-table` with `table-toolbar`, `saved-views`, `filter-builder`, `column-menu`, `row-selection`, sortable
columns and `pagination` → `bulk-action-bar` → `toast` from Export → `confirm-dialog` from Remove. The build
stamp lists the components used.

**Verified.** Light and dark; comfortable and compact; 1440, 1280 and 390 wide; one scroll region with the rail
fixed; no console errors; Export raises a toast; selecting a row raises the bulk bar; a column sorts; Remove opens a
confirm dialog that names what is lost, focuses Cancel and returns focus to Remove.

**Tokens.** None of its own. Everything comes from the components it uses.

**Provenance.** NEW, pending library review. It is deliberately not listed on the hub's public Templates page
yet: adding its card there is the step that makes it live, and it waits for a pass.
