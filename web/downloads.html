Tokens

Every color, type step, space and radius as a CSS custom property. Inside Claude Code the plugin already serves these — this is for everything else.

  --gw-color-primary-500: #0070ff;
  --gw-text-display-40-semi: 600 40px/1.2 …;
  --gw-space-40: 40px;
  --gw-radius-8: 8px;
}

What isn’t here

Deck templates, the lead-magnet shell and the dashboard kit ship with the Claude plugin rather than as loose files — a template that gets downloaded is a template that goes stale. Icons come from Phosphor over CDN, so there is nothing to take there either.
