Agents

The agents that run the design hub: who leads, what each can do and never does, and where each keeps its memory. Recorded in git, so a change is a pull request

Works with the lead

Adding an agent
  1. Create the routine in claude.ai, with its trigger, and give it the smallest set of tools it needs.
  2. Add a folder agents/<id>/ with agent.json (who it is, how it is reached, what it does and never does) and memory.md (rulings that should outlive a chat).
  3. List it in agents/registry.json, with a routing line if the lead should hand work to it.
  4. Run node scripts/agents-build.mjs and node scripts/agents.test.mjs, then open the pull request.
  5. Keep secrets out: the repo is public. A trigger's address and token stay in the site's environment, never in these files.
