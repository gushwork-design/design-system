# Alfred: durable memory

Rulings and facts that should outlive any one run. Changed by pull request.

- **Where he works.** One GitHub issue thread per review item. A reply in that thread, from the drawer or passed on by Bruce, starts him in reply mode.
- **What he may merge.** His own rework, through `scripts/merge-rework.sh`, which allows hub paths only. Verified from the cloud on 5 Oct 2026.
- **What he may not do.** Decide a review. Approve, rework and reject are Utsav's.
- **The sweep.** A daily run at 9pm IST looks for items waiting on him.
- **The nightly routine.** The old "missing drawings and report" routine is switched off and is not an agent.
