Gushwork design system

A Claude Code plugin. Install it once, and Claude builds Gushwork screens using the real components and tokens instead of guessing at them.

v1.44.0 · last updated 1 Sep 2026, 19:53 · changelog

Install

1 · Install it

One line, in any terminal. It adds the marketplace, installs the plugin, and turns on auto-update — and it is safe to re-run, so it is also the fix if you are not sure what state you are in.

curl -fsSL https://raw.githubusercontent.com/gushwork-design/design-system/main/scripts/install.sh | bash

Needs Claude Code on your PATH and git able to reach the repo. It checks both up front and tells you which one is missing rather than failing three steps later.

OR

Don't want to use a terminal? Paste this into Claude Code instead and approve what it runs. Same result.

Set up the Gushwork Design System plugin for me:

1. Run: claude plugin marketplace add gushwork-design/design-system
2. Run: claude plugin install gushwork-design@gushwork

Then tell me to restart Claude Code.

2 · Restart Claude Code

The plugin does not take effect in the session you installed it from. Quit and start it again — this is the step people miss.

Verify

1 · Check it's installed

You should see gushwork-design in the list.

claude plugin list

2 · Check it fires

Ask Claude to build something with the Gushwork design system — a dashboard, a landing page, whatever you're working on. You don't have to name the skill; it triggers on the work.

The reply must open with one of these, depending on what you asked for:

Using the Gushwork dashboard skill — v1.44.0, updated 1 Sep 2026.
Using the Gushwork web skill — v1.44.0, updated 1 Sep 2026.
Using the Gushwork lead-magnet skill — v1.44.0, updated 1 Sep 2026.

If that line is missing it didn't fire — restart again, or ask for the skill by name. The version in it is also how you catch a stale install: if it reads anything below v1.44.0, you're behind and it's emitting old values. It will ask two or three questions before building. That's deliberate.

Staying current

1 · Your session tells you when you're behind

You no longer have to check. At the start of a session the plugin compares the copy you are running against the published one, and speaks up only if it has moved — naming the components that changed and which of them break a screen built on the old ones.

Gushwork design system v<latest> is out — this session is on v<yours>.
1 breaking: badge · 4 changed. Auto-update was off on this machine —
it is on now, so the next start picks this up.

Silence means you're current. The check is time-boxed and fails quietly, so a flaky network costs you nothing.

2 · Auto-update turns itself on

Keeping it on used to be a manual edit to a config file, which is exactly why it got skipped — and a skipped flag means emitting last month's colours and spacing with full confidence. No error, no warning. The same session check sets it for you, once.

An update lands in the background and takes effect at your next start, never the current one. To take one immediately:

claude plugin update gushwork-design@gushwork

Restart afterwards either way.
