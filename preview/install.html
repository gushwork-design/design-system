Gushwork Design Plugin

v1.48.0

Last updated 23 Sep 2026, 11:59 · Change log

A Claude Code plugin. Install it once and Claude builds Gushwork pages, screens, decks and lead magnets from the real tokens and components instead of guessing at them.

How to install?

One command and a restart. You do this once — after that it keeps itself up to date.

Step 1: Copy the command and paste it in Claude Code, or run it in a terminal

It adds the marketplace, installs the plugin and turns on auto-update. Safe to re-run — so it is also the fix when you are not sure what state you are in.

curl -fsSL https://raw.githubusercontent.com/gushwork-design/design-system/main/scripts/install.sh | bash

Step 2: Restart Claude

The plugin does not take effect in the session you installed it from. This is the step people miss.

Step 3: Confirm it installed

Copy and paste this in Claude Code. You should see gushwork-design in the list.

claude plugin list

That's it. Auto-update is on, so a session that has fallen behind says so at the start — naming what changed and what breaks. Silence means you are current.

How to use it?

Ask for the work, not the skill. Claude reads the request and loads the right one.

"Build an ad page for Meta", "add a KPI row to the dashboard", "a discovery deck for this prospect" — you never name a skill, and you don't need to know which one covers what. See what it covers below.

You know it fired when the reply opens with a line like:

Using the Gushwork web skill — v1.48.0, updated 23 Sep 2026.

That version is also your stale-install check. Anything below the current release and you are getting old values.

Expect two or three questions before it builds. What surface, who it is for, what the page has to do. That is deliberate — the answers are what keep it from guessing, and guessing is what the plugin exists to stop.

What can it do?

Four surfaces today, all built from the same tokens, components and voice rules this site documents.

Marketing pages: landing pages and ad landers, heroes, pricing pages, comparison tables, testimonials, case studies, FAQs, navbars, footers, forms.

Product screens: dashboards, app screens, KPI cards, analytics panels, data tables, side navigation, filters, tabs, toasts, account chrome.

Slide decks: sales, pitch, prospect and client decks, QBRs, investor updates, all-hands. Emits static HTML, a real .pptx, or a Google Slides deck.

Lead magnets: the downloadable PDF behind an ad lander — checklists, prompt packs, audit worksheets, playbooks, teardowns, buyer guides.

That is what ships today, and it is the difference between Claude approximating the brand and reading it.

More is on the way. A longer list of skills lands over the next few weeks, covering surfaces this does not reach yet.

You do not have to watch for them. Auto-update brings each one down on its own, and Claude tells you at the start of a session when the system has moved, naming what changed and what breaks a screen built on the old version. Nothing to check, nothing to subscribe to. The Change Log has the full history whenever you want the detail.
