A shared atom — both surfaces use it. Drawn in ↳ web/ component-library → input-fields, but dashboard-login-screen instantiates it too, so it is read from foundation/text-field.md and both skills own it. DECISIONS.md → R1.
The fill is neutral/50 in all 14. It never changes — not on hover, not on focus, not on error. State=Hover is byte-identical to State=Default, so the field has no hover treatment; its affordance is the caret and its feedback is Selected. That is the one documented exception to "every interactive element has a hover" — R2. :focus-visible is mandatory precisely because nothing else moves.

GW Dashbords  Q9L6q38dEj3Qu1JkjiT13y → page 257:371 — 24 sets + 3 components, 132 variants

provenance read this first

These components live in the product file, not the design system library, and are not published — so they cannot be instanced from any other Figma file. For generating code that does not matter; for telling someone where to find them it does. The screens were built by detaching library components and overriding them — list-item detached 34 times into nine different jobs — because the library’s dashboard components did not match what shipped. Utsav ruled the screens authoritative on 13 Aug 2026 (R14). Full supersession map: exports/dashboard/v2/README.md.

⚠ The display type ramp has no tokens (R15). The five Dashboard/display-* styles match no --gw-text-* property — 44 is Semibold where h3 is Bold, 22 is line-height 1.0 where h7 is 1.4, and 36/28/20 have no display step at all. Every title rendered on this page is therefore unbound. Use the literal spec and comment it; never substitute h3 or h7.

Updated 14 Aug: dark variants now exist for table-row, table-cell, icon-button, input, tab-group and icon-toggle-group, and TEXT/BOOLEAN component properties were added to control, badge, tab-item, table-cell, stat-card, metric-card and tooltip. Dark specimens are drawn beside their light counterparts and captioned DARK — 21 of them, added this pass. One value was corrected while rendering: dark table header text is neutral/100, not the neutral/400 first recorded.

Not rendered on this page: hover, focus and disabled states (v2 defines hover only on table-row — read button.md and states.md); the open dropdown menu; Graph, which v2 does not cover at all; and the full 5-column table width. Several specimens are rendered narrower than the component to fit this sheet and say so in their note.
